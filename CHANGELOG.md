# Changelog

## 0.1.0
- First release: script-to-scenes editor, image/video/voice/music import, per-scene durations,
  FFmpeg rendering with transitions, fades, color looks, music ducking, subtitles (burned-in
  or selectable track), project save/open, progress + safe cancel, export validation.
- Windows installer (Inno Setup) built and tested by GitHub Actions.
